Работа выполнена на основе `attracrion-finder (2).zip`. В исходном проекте
имелись класс `Attraction`, JSON-хранилище, консольное меню и тесты ПР3.

и сразу реализован конечный шаблонный интерфейс ПР6.

## Выполненная доработка

Код распределён по папкам: `core` — предметная область и JSON-хранилище,
`cli` — консольное меню, `config` — настройки Django, `web` — приложения,
`templates` — общие шаблоны, `static` — оформление, `tests` — проверки,
`docs` — отчёт и материалы защиты. Существующие данные сохранены.

Создан `base.html` с блоками `title` и `content`. Страницы наследуют его
через `extends`. Навигация, подвал, карточка достопримечательности и её
статус вынесены в шаблоны, подключаемые через `include`.
Представления загружают объекты из JSON и передают контекст в `render()`.
Коллекции выводятся через `for`, пустое состояние — через `empty`,
статус и бесплатное посещение — через `if`.

Настроены именованные маршруты и пространства имён. Ссылки формируются
через `url`. Применены фильтры `length`, `date`, `default`, `capfirst`,
`floatformat`, `truncatechars`, `slice`, `stringformat`.
Подключены собственный адаптивный CSS, SVG-логотип и иллюстрация города.
JavaScript переключает показ только открытых мест. Функция `page()`
и формирование HTML в Python не используются.

## Результат и проверка

Реализованы главная страница, список и карточка достопримечательностей,
список категорий и страница категории. Такая структура адаптирует пять
страниц примера Roomly к предметной области исходного проекта.
Несуществующие объекты возвращают HTTP 404. ORM и формы не внедрялись.

`python manage.py check` — ошибок нет. `python -m pytest -v` — 35 тестов
пройдены. `python -m flake8 .` — замечаний нет. Дополнительно в браузере
проверены пять страниц на широком и мобильном экране, загрузка ресурсов
и работа JavaScript-фильтра. Скриншоты находятся в `docs/screenshots/`,
журнал проверок — в `docs/VERIFICATION.txt`.
