# Сервис поиска достопримечательностей

## Назначение
Небольшое приложение, которое помогает найти достопримечательности в городе — 
например, по категории (музей, парк и т.д.) — и посмотреть базовую информацию 
о них: адрес, часы работы, цену билета.

## Целевая аудитория
Туристы и просто жители города, которые хотят посмотреть, куда можно сходить, 
не листая кучу разных сайтов.

## Предметная область
Достопримечательности города: музеи, парки, памятники и подобные места, куда 
можно сходить в свободное время.

## Основные сущности
- Достопримечательность (название, категория, адрес, часы работы, цена билета)
- Категория (музей, парк, памятник и т.д.)
- Город

## Основные функции
- Поиск достопримечательности по названию
- Фильтр по категории
- Проверка, открыто ли место прямо сейчас
- Расчёт цены билета с учётом скидки
