# ПР7 — что показать и что объяснить

Запуск: `.\.venv\Scripts\python.exe manage.py runserver`.
Главное отличие от ПР6: страницы читают SQLite, а JSON нужен для импорта
и сохранённой консольной версии. ORM пока нет.

## Короткие уточнения

- База данных — хранимые данные; СУБД — программа, которая ими управляет.
- SQLite хранит базу в файле и не требует отдельного сервера.
- В SQLite есть NULL, INTEGER, REAL, TEXT, BLOB. В нашей схеме цена REAL,
  часы INTEGER, названия TEXT, описание может быть NULL.
- NULL означает отсутствие значения: проверка `IS NULL`, а не `= NULL`.
- WHERE фильтрует строки до группировки, HAVING — группы после неё.
- JOIN оставляет совпавшие строки, LEFT JOIN сохраняет также пустые категории.
- COUNT(a.id) после LEFT JOIN даёт 0 для пустой категории; COUNT(*) дал бы 1.
- ORDER BY задаёт порядок; ASC — по возрастанию, DESC — по убыванию.
- LIMIT ограничивает число строк, OFFSET пропускает начало. Нужен стабильный
  ORDER BY, чтобы состав страниц был предсказуемым.
- В SQL `=` означает равенство, `<>` и `!=` — неравенство.
- IN — входит в набор; BETWEEN — включительно между границами;
  LIKE — шаблон с `%` и `_`; DISTINCT — уникальные значения.
- Наш поиск использует instr(search_name, ?) для буквального вхождения:
  `%` не становится специальным шаблоном. casefold поддерживает русский регистр.
- MIN/MAX — минимум/максимум, AVG — среднее, SUM — сумма.
- Логически: FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.
- cursor хранит результат выполнения; fetchone получает строку, fetchall — список.
- rollback отменяет незавершённые изменения, close освобождает соединение.
- `:memory:` — база только в памяти, исчезает после закрытия соединения.
- Повторный импорт обновляет совпадающие ID и не удаляет лишние записи.
- Модель работает с ежедневным расписанием, поэтому поиск по часу — аналог
  поиска доступности по дате из Roomly. Календаря бронирований у нас нет.

Для опытов с UPDATE/DELETE создайте data/demo.sqlite. Рабочий файл
data/attractions.sqlite и исходный JSON для демонстрации очищать не нужно.
