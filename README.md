# Город рядом — сервис поиска достопримечательностей

Индивидуальный проект после ПР6 «Шаблоны Django и проектная разработка».
В основе — ваш архив `attracrion-finder (2).zip` и существующий класс
`Attraction`. Консольное приложение ПР3 сохранено, к нему добавлен веб-интерфейс.
Поскольку ПР4–ПР5 отсутствовали, необходимая основа Django создана сразу
с шаблонами ПР6. Промежуточная генерация HTML в Python не добавлялась.

## Быстрый запуск в Windows

Нужен установленный Python 3.10 или новее. Откройте терминал в папке,
где находится `manage.py`, и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. Остановить сервер: `Ctrl+C`.
Если команда `py` недоступна, используйте `python` в первой команде.
Активация окружения не требуется: команды напрямую вызывают его Python.
Миграции, создание базы и суперпользователя не нужны.

Консольная версия:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Возможности и страницы

| Страница | Адрес | Имя маршрута |
| --- | --- | --- |
| Главная | `/` | `homepage:index` |
| Все достопримечательности | `/attractions/` | `catalog:list` |
| Отдельное место | `/attractions/1/` | `catalog:detail` |
| Категории | `/categories/` | `categories:list` |
| Места категории | `/categories/музей/` | `categories:detail` |

Сортировка по цене: `/attractions/?sort=price`.
Кнопка «Только открытые сейчас» фильтрует карточки средствами JavaScript.
При отключённом JavaScript страницы и ссылки продолжают работать.
Отсутствующие объекты и неправильные адреса возвращают HTTP 404.
При `DEBUG=True` Django показывает диагностическую 404; чтобы увидеть
оформленную страницу, задайте `$env:DJANGO_DEBUG="0"` перед запуском.
Для локального показа статики в этом режиме используйте
`manage.py runserver --insecure` (только для демонстрации на своём компьютере).

Roomly в методичке — пример. Для этого варианта список и карточка помещений
соответствуют списку и карточке достопримечательностей; список и карточка
бронирований заменены списком и страницей категории. Категории вычисляются
из существующих объектов `Attraction`, чужие сущности Room/User/Booking
и искусственные данные не добавлялись.

## Как устроена ПР6

Запрос → `config/urls.py` → маршруты приложения → view → JSON и объекты
`Attraction` → словарь контекста → шаблон → HTML-ответ.

- `base.html` содержит общую разметку, блоки `title`, `content` и статику.
- Все пять страниц наследуют его через `{% extends "base.html" %}`.
- `{% include %}` подключает навигацию, подвал, карточку и статус места.
- Представления вызывают `render()` и передают данные через контекст.
- `{% for %}` выводит коллекции, `{% empty %}` сообщает об отсутствии данных.
- `{% if %}` выбирает статус работы и подпись «Бесплатно».
- Ссылки используют `{% url %}`, `name` и пространства имён `app_name`.
- Фильтры: `length`, `date`, `default`, `capfirst`, `floatformat`,
  `truncatechars`, `slice`, `stringformat`.
- Собственные CSS, JavaScript и SVG-изображения подключены через `static`.
- HTML в Python не формируется, функции `page()` нет.
- Автоматическое экранирование включено, `safe` не используется.

## Сохранённая функциональность

`Attraction` хранит id, название, категорию, часы работы и цену;
сохраняет методы `is_open_now`, `calculate_price`, `from_data`, `to_dict`,
`__str__`. Сохранены добавление, поиск, фильтрация, сортировка и расчёт скидки
в консоли. После перемещения модулей обновлены импорты и пути mock в тестах;
исходные 10 тестовых сценариев и их утверждения сохранены.

JSON читается при каждом запросе, веб-страницы его не изменяют. Добавлять
места можно через прежнее консольное меню. Путь к JSON в консоли теперь
определяется относительно проекта, а не текущей папки терминала.

Статус «открыто» сохраняет логику ПР3: используется локальный час компьютера
с сервером, интервал `[open_hour, close_hour)`. Ночные интервалы, выходные,
праздники и часовые пояса отдельных мест пока не моделируются.

## Проверки

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 .
```

Проверяются все пять страниц, наследование, 404, пустые списки,
экранирование HTML, сортировка, категории, статусы на границах часов,
неизменность JSON, статические файлы и консольная версия.
Результаты реального запуска — в `docs/VERIFICATION.txt`.
